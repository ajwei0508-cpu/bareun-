# 바른한의원 대전본점 (Bareun Clinic)

바른한의원 대전본점 프로젝트 공식 저장소입니다.

## 📂 프로젝트 구조

- **`homepage/`**: 바른한의원 하이엔드 인터랙티브 웹사이트 및 비대면 처방 페이지
  - `index.html`: 메인 인트로 및 바른 비대면 카드 인터랙션
  - `diet-zero.html`: 식욕 ZERO 핑크 시크릿 플랜 상세페이지
  - `serve.js`: 로컬 개발 및 프리뷰 서버 (포트 3000)
  - `style.css`: 최고급 스위스 에디토리얼 & 럭셔리 스타일시트
  - `app.js`: 인터랙티브 카드 & 모션 스크립트

## 🚀 로컬 프리뷰 서버 구동
```bash
cd homepage
node serve.js
```
브라우저에서 `http://localhost:3000` 접속
